## 开发线索

- 扩展源码在 `packages/extension/new_shenhua`，构建产物在 `apps/core/extension/new_shenhua`。
- 改源码后运行 `pnpm -F @noname-extension/new_shenhua build`，会把 `src/*`、图片、`info.json` 等写到游戏实际加载目录。
- 技能参考优先在本体里搜：`apps/core/character/shenhua/skill.js`、`apps/core/character/refresh/skill.js`，再看对应 `translate.js` 确认文案。
- 小乔已做：`红颜` 参考本体 `xinhongyan`（黑桃视为红桃 + 红桃判定生效前改花色）；`天香` 参考 `retianxiang`/`oltianxiang`，但限定弃置红桃手牌，第一项用 `trigger.num` 对目标造成等量伤害，而不是固定 1 点。
- `天香` 的关键实现点：触发 `damageBegin4` 后先 `trigger.cancel()` 防止本次伤害；选项一调用 `target.damage({ num: trigger.num, source: trigger.source, nocard: true })`，无来源时用 `nosource: true`；选项二令目标 `loseHp()`，再在弃牌仍在牌堆/弃牌区时获得该牌。

## 火

- [x] 庞德（群，4/4，人马一体）
  - 马术：锁定技，你计算与其他角色的距离-1。出牌阶段开始时，你可将一张黑色牌当【杀】使用。
  - 鞬出：当你使用【杀】指定目标后，你可以弃置该角色的一张牌。若弃置的牌为装备牌，其不能使用【闪】响应此【杀】；若弃置的牌不为装备牌，其获得此【杀】。
  - 注释：普通庞德“鞬出”+ 新“马术”。实现时直接引用 `new_standard_mashu`，避免重复实现马术。

- [x] 卧龙诸葛（蜀，3/3，卧龙）
  - 八阵：锁定技，若你的防具栏未被废除且为空，你视为装备着【八卦阵】。
  - 火计：你可以将一张红色牌当【火攻】使用；当你因使用【火攻】而需要弃置牌时，你可以观看牌堆顶的三张牌并如手牌般弃置之。
  - 看破：你可以将一张黑色牌当【无懈可击】使用；你使用的【无懈可击】不能被响应。
  - 注释：经典版“八阵”+ OL界“看破”+ 新“火计”；需要制作/修改“火计”。

- [x] 庞统（蜀，3/3，凤雏）
  - 连环：你可以将一张♣牌当【铁索连环】使用或重铸，你使用【铁索连环】可以多指定一名角色为目标。
  - 涅槃：限定技，当你处于濒死状态时，你可以弃置区域里的所有牌，复原武将牌，摸三张牌，将体力回复至3点，然后获得“八阵”“火计”“看破”中的一个。
  - 注释：同 OL界庞统，但“涅槃”后的衍生技改为新卧龙的技能；需要制作/修改“涅槃”。

- [x] 颜良文丑（群，4/4，虎狼兄弟）
  - 双雄：摸牌阶段结束时，你可以弃置一张牌。若如此做，本回合你可以将一张与此牌颜色不同的牌当【决斗】使用；当你因【决斗】受到伤害后，你可以获得此次【决斗】中其他角色打出的【杀】。
  - 注释：OL界触发方式（摸2弃1）+ 手杀受伤后立即捡杀；需要制作/修改“双雄”。
